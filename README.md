Unemployment Analysis in India

Project Overview

This project analyzes unemployment trends in India using Python. It explores unemployment rates across different states and regions and examines changes during the COVID-19 period.

Tools & Technologies

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

Key Analysis

- Data Cleaning and Preprocessing
- State-wise Unemployment Analysis
- Monthly Unemployment Trends
- COVID-19 Impact Analysis
- Rural vs Urban Comparison
- Top 10 States with Highest Unemployment

Conclusion

This project provides insights into unemployment patterns across Indian states and regions.
